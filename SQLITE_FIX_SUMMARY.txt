COMO USAR:

  1. Teste com SQLite:
     $ DB_CONNECTION=sqlite php artisan migrate:fresh
     $ php artisan migrate:status

  2. Teste com MySQL:
     $ DB_CONNECTION=mysql php artisan migrate:fresh
     $ php artisan migrate:status

  3. Se encontrar problemas:
     $ php artisan config:clear
     $ composer dump-autoload
     $ php artisan migrate:fresh

PADRÃO DE PROTEÇÃO APLICADO:

  if (DB::getDriverName() !== 'sqlite') {
      $table->dropForeign([...]);
  }

  Esta verificação:
  • Ignora dropForeign em SQLite
  • Executa normalmente em MySQL, PostgreSQL, etc.
  • Permite que colunas sejam removidas sem erros
